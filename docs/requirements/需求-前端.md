# 前端需求文档（Portal + Admin）

| 文档版本 | V1.0 |
| --- | --- |
| 编制日期 | 2026-10-18 |
| 依据 | 系统设计文档 V5.1 |
| 技术栈 | **Vue 3 + Element Plus** · 百度地图 JS SDK · Axios |
| 范围 | 网页前台 Portal、网页后台 Admin（不含 APP） |

---

## 1. 文档说明

### 1.1 目的

定义 PC 端两个 Web 应用的**信息架构、页面结构、交互流程、权限显隐、实时刷新与视觉规范**，供 UI/前端开发与验收使用。后端接口见 [`需求-后端.md`](需求-后端.md)。

### 1.2 产品原则

| 原则 | 说明 |
| --- | --- |
| 职责任分离 | Portal **只读展示**；Admin **管理与录入**；不做现场扫码/打卡 |
| 权限驱动 UI | 菜单、按钮、操作列按 `permissions` 裁剪；无权限不展示入口 |
| 同栈分应用 | 两个独立 Vue 应用，共享组件库与设计 Token |
| 实时优先 | 告警/监测/点位通过 WSS（Protobuf）增量刷新；列表进页走 REST |

### 1.3 应用一览

| 应用 | 路径建议 | 访问权 | 布局 |
| --- | --- | --- | --- |
| Portal | `/portal` 或 `portal.` 子域 | `portal:access` | **上下**：顶栏菜单 + 全宽内容 |
| Admin | `/admin` 或 `admin.` 子域 | `admin:access` | **左右**：侧栏导航 + 顶栏 + 内容 |

## 2. 全局交互与视觉

### 2.1 设计 Token（建议）

| Token | 建议值 / 规则 |
| --- | --- |
| 主色 | 工业安全向深蓝/青绿（避免默认紫渐变）；告警红 `#D93025`、预警橙、正常绿 |
| 字体 | 中文优先系统字体栈或「思源黑体 / PingFang」；数字等宽 |
| 圆角 | 卡片 4–6px；按钮跟随 Element Plus 默认即可 |
| 密度 | Admin 表格偏紧凑；Portal 卡片偏舒展 |
| 暗色 | 本期不做强制暗色；Portal 大屏可后续加 |

### 2.2 公共交互

| 场景 | 行为 |
| --- | --- |
| 登录 | 账号密码 / LDAP；成功后若 `mustChangePassword` → 强制改密页，不可跳过 |
| Token | Access 过期用 Refresh 静默续期；Refresh 失败跳登录 |
| 无权限 | 菜单隐藏；直链 URL → 403 空态页 |
| 全局顶栏 | 用户名、角色摘要、未读告警角标、退出 |
| 消息 | Element Plus `ElMessage` / `ElNotification`；严重告警可用通知 |
| 空态 | 插画或简文案 + 操作引导（Admin） |
| 加载 | 表格骨架屏 / `v-loading`；地图独立 loading |
| 确认 | 删除、作废、驳回等破坏性操作用 `ElMessageBox` |
| 导出 | 物资/报表等：按钮 → 下载中 → 完成提示 |

### 2.3 实时连接

1. 登录后（有 `monitor:view` / `alarm:view` / `track:view` 等）建立 WSS（经网关鉴权反代）。
2. 收到 Protobuf `PushEnvelope` 后按 `msg_type` 更新：告警列表角标、监测卡片数值、地图点位。
3. 断线自动重连（指数退避）；重连成功后 REST 拉一次快照纠偏。
4. 通知栏类能力由 APP 承担；Portal/Admin 以站内通知为主。

### 2.4 地图（百度）

- Portal：运输轨迹、实时点、围栏只读展示。
- Admin：围栏绘制（圆/多边形）、单元位置预览。
- 统一坐标系与地图样式；围栏编辑需吸附、撤销、保存二次确认。

## 3. 登录与账户

### 3.1 画面：登录页

| 元素 | 说明 |
| --- | --- |
| 品牌区 | 系统名称「智能危废管控」+ 简短副标题 |
| 表单 | 用户名、密码；可选「LDAP 域账号」提示文案 |
| 主按钮 | 登录 |
| 错误 | 账号密码错误、无端访问权、账号停用 |

**交互**：登录成功 → 若强制改密进改密页 → 否则按 `clients` 进入有权应用（仅有 portal 则进 Portal）。

### 3.2 画面：强制改密

| 元素 | 说明 |
| --- | --- |
| 字段 | 原密码、新密码、确认密码 |
| 规则 | 展示密码强度要求（与后端一致） |
| 完成后 | 重新登录或直接进入系统 |

### 3.3 画面：个人中心（轻量）

两端均可：改密、查看权限摘要、退出。Admin 不提供在 Portal 改角色。

## 4. Portal（网页前台）需求

### 4.1 信息架构（顶栏）

```
[品牌]  工作台 | 告警 | 物资 | 盘点 | 监测 | 地图 | 围栏 | 巡检报表   [告警角标] [用户]
```

菜单显隐规则：

| 菜单 | 权限 |
| --- | --- |
| 工作台 | `portal:access` |
| 告警 | `alarm:view` |
| 物资 | `material:view` |
| 盘点 | `inventory:view` |
| 监测 | `monitor:view` |
| 地图 | `track:view` |
| 围栏 | `geofence:view` |
| 巡检报表 | `inspection:view` |
| 跳转 Admin | 另有 `admin:access` 时显示入口 |

### 4.2 工作台

**画面结构**

```
┌─ 顶栏 ─────────────────────────────────────┐
├─ 指标卡片行：未确认告警 | 库容 | 在途任务 | 环境摘要 ┤
├─ 左：告警滚动/最新列表    右：监测状态灯/迷你曲线 ──┤
└─ 底：快捷入口（下钻到各菜单）─────────────────────┘
```

| 交互 | 说明 |
| --- | --- |
| 卡片点击 | 跳转对应模块并带筛选（如未确认告警） |
| 实时 | 告警数、环境指标、在途点 WSS 更新 |
| 刷新 | 手动刷新 + 进入页 REST 拉取 |

### 4.3 告警中心

**布局**：筛选条 + 表格/卡片列表 + 右侧或抽屉详情。

| 筛选项 | 说明 |
| --- | --- |
| 状态 | 待确认 / 已确认 / 已关闭 |
| 级别 | 紧急 / 重要 / 一般 |
| 类型 | 超阈 / 越界 / 入侵 / 水浸 / 库容 / 其他 |
| 时间 | 起止 |

| 操作 | 权限 | 交互 |
| --- | --- | --- |
| 查看详情 | `alarm:view` | 抽屉：规则、测点值、阈值、关联设备、时间线 |
| 确认 | `alarm:ack` | 填确认说明 → 成功后行状态变更；无权限隐藏按钮 |
| 关闭 | `alarm:ack` | 二次确认 |

列表支持未确认置顶；新告警 WSS 插入顶部并闪烁一行。

### 4.4 物资总览

**布局**：筛选（物资类型、状态、唯一码、库区）+ 表格 + 详情抽屉。

| 列建议 | 唯一码、物资名称、类别、数量/状态、库位、入库时间、库龄 |
| --- | --- |
| 交互 | 只读；可导出（需 `material:export`）；点唯一码看生命周期时间线 |
| 禁止 | 无编辑、无调整库存入口 |

### 4.5 盘点报表

- 列表：任务名称、仓/库区、状态、完成时间、差异数。
- 详情：实盘汇总表、差异明细；支持下载报表（权限 `inventory:view`）。
- 无创建任务、无扫码入口。

### 4.6 智能监测

```
┌ 设备/测点切换 ────────────────────────────┐
├ 实时数值卡片（温湿度/水浸/入侵）+ 状态灯 ──┤
├ 历史曲线（时间范围选择）──────────────────┤
└ 可选：视频位（若配置摄像头，嵌入播放器）──┘
```

| 交互 | WSS 更新实时值；曲线用 REST 历史；超阈卡片变色并链到告警 |
| --- | --- |

### 4.7 运输地图

```
┌ 左侧任务/单元列表 │ 右侧百度地图（点位+轨迹回放）┐
└ 底部：时间轴回放控件 ─────────────────────────┘
```

| 交互 | 选任务看轨迹；实时点 WSS 更新；点击点位气泡显示单元信息 |
| --- | --- |
| 禁止 | 无打卡、无任务编辑 |

### 4.8 围栏状态

- 地图展示围栏多边形/圆（只读）。
- 右侧越界事件列表；点击定位到地图。
- 无绘制工具。

### 4.9 巡检报表

- 任务列表与完成率；点开看打卡点、照片缩略图（灯箱）、异常项。
- 只读；无创建计划。

## 5. Admin（网页后台）需求

### 5.1 信息架构（侧栏）

按权限显隐，建议分组：

```
概览
人员与权限        用户 / 角色 / 审计日志
仓储与物资        入库 / 出库 / 唯一码 / 物资档案 / 库存调整
盘点              任务管理
运输              运输任务 / 运输单元 / 打卡记录(只读)
安全与监测        阈值 / 围栏 / 设备 / 告警处置
巡检              计划 / 路线 / 任务
审批              待我审批 / 我发起的 / 审批模板
对接与配置        MQTT Schema / 监管对接
```

顶栏：面包屑、全局搜索（可选）、告警角标、用户。

### 5.2 概览页

- 待办：待审批数、待执行盘点、未确认告警。
- 快捷入口：开入库单、建盘点、建巡检任务。

### 5.3 人员与权限

#### 用户管理（`user:view/edit`）

| 画面 | 列表 + 新建/编辑抽屉 |
| --- | --- |
| 字段 | 账号、姓名、手机、部门、状态、角色多选、端访问、仓库 Scope、是否 LDAP |
| 操作 | 启用/停用、重置密码、保存 |

#### 角色管理（`role:view/edit`）

| 画面 | 角色列表 + 权限点矩阵（树形勾选，按模块分组） |
| --- | --- |
| 交互 | 保存后提示「即时生效」；预览「该角色在 Portal/Admin/APP 可见菜单」只读示意 |

#### 审计日志（`audit:view`）

筛选：操作者、类型、时间；表格只读；详情 JSON/字段对照。

### 5.4 仓储与物资

#### 入库（`inbound:edit` / `code:issue`）

| 步骤向导 | ① 申报/基本信息 → ② 明细行 → ③ 提交开单 → ④ 发码/打印 |
| --- | --- |
| 发码 | 批量生成唯一码；表格展示；打印预览（标签模板） |
| 状态 | 草稿/已开单/执行中/已完成；列表可筛选 |

**禁止**：页面上不做扫码上架（提示「请在 APP 确认」）。

#### 出库（`outbound:edit`）

- 选择在库唯一码/物资 → 开出库单 → 可关联联单号。
- 可从出库单一键「创建运输任务」（跳转并带出库单 ID）。

#### 物资档案（`material:edit`）

- CRUD；字段：名称、类别、危废代码、规格、单位等。
- 库存只读展示；调整走「库存调整」流程。

#### 库存调整（`stock:adjust`）

```
填写调整单 → 提交 → 进入多级审批
审批中：只读查看进度条（第几级/待谁审）
通过后：库存数更新；驳回：显示原因，可重新发起
```

### 5.5 盘点

| 画面 | 任务列表、创建任务（库区/物资范围/执行人）、进度、差异复核 |
| --- | --- |
| 创建 | `inventory:create`；执行在 APP |
| 差异过账 | `inventory:adjust`；若配置审批则走审批 |
| 报表 | 查看/导出 |

### 5.6 运输

#### 运输任务（`transport:edit`）

- 表单：出库单、单元、驾驶员、计划节点。
- 状态：待发/在途/已签收。
- 打卡记录：时间线只读（照片缩略图、定位）。

#### 运输单元（`unit:edit`）

- 车辆/转运仓 CRUD；绑定定位设备。

### 5.7 安全与监测

#### 阈值（`threshold:edit`）

- 按测点：上下限、库容、水浸/入侵策略、通知人。
- 保存成功提示「已热加载」。

#### 围栏（`geofence:edit`）

```
┌ 工具条：圆/多边形/编辑/删除/撤销 ┐
├ 百度地图画布                      │
└ 属性：名称、滞回、生效时段、启用   ┘
```

保存前预览；保存后生效。

#### 设备（`device:edit`）

- 网关/传感器/摄像头注册；绑定仓与 Schema Profile。

#### 告警处置

- 与 Portal 类似列表；偏管理筛选；确认/关闭。

### 5.8 巡检（本期）

| 画面 | 能力 |
| --- | --- |
| 计划 | 周期、负责人（`inspection:create`） |
| 路线 | 有序巡检点：名称、定位、是否必拍 |
| 任务 | 下发到执行人；看 APP 回传进度、照片、异常 |
| 异常 | 一键转告警（若有权） |

### 5.9 审批

| 画面 | 说明 |
| --- | --- |
| 审批模板 | 业务类型、级数 N、每级角色/人、通过策略（任一面/全员） |
| 待我审批 | 卡片/表格；通过须填意见；驳回必填原因 |
| 我发起的 | 进度时间线 |
| 进度条 | 可视化 1..N 级状态（待办/通过/驳回） |

无 `approval:act` 不显示「通过/驳回」。

### 5.10 MQTT Schema（`mqtt:schema:edit`）

- Profile 列表；编辑样例 JSON、字段映射、版本发布。
- Topic 模板；设备绑定。
- **Dry-run**：粘贴原始报文 → 预览 Canonical。
- 交互参考原型 `archive/prototypes/web-admin/mqtt-schema.html`。

### 5.11 监管对接（`openapi:config`）

- OpenAPI/SFTP 开关、地址、证书、字段映射。
- Outbox 投递日志只读；失败可「重试」。

## 7. 非功能（前端）

| 项 | 要求 |
| --- | --- |
| 浏览器 | Chrome / Edge 近两个正式版；1920 与 1366 宽度可用 |

| i18n | 本期中文 |

## 8. 验收要点

1. 无权限菜单与按钮均不可见；直链 403。
2. Portal 任意页面无「开单/发码/画围栏/扫码」入口。
3. Admin 开单后状态与 APP 确认后 Portal 物资/工作台数据一致。
4. 多级审批进度展示正确；驳回后库存不变。
5. 围栏绘制保存后 Portal 只读可见；越界事件可联动。
6. WSS 断开重连后数据不长时间脏读（有快照纠偏）。
7. 强制改密流程不可绕过。
