# 架构与组网示意图（补充）

> 与《智能危废管控系统设计文档》配套，便于评审与实施交底。

## 1. 多模式组网拓扑

```
                    ┌────────────────────────────┐
                    │  智能危废管控后台（云/机房）  │
                    │  API · MQTT · 规则 · 推送   │
                    └─────────────▲──────────────┘
                                  │
          ┌───────────────────────┼───────────────────────┐
          │                       │                       │
   【公网模式】              【局域网模式】            【物联网模式】
   4G/5G 路由器              企业专网/Wi-Fi            LoRa / NB-IoT
          │                       │                       │
          ▼                       ▼                       ▼
   ┌─────────────┐         ┌─────────────┐         ┌─────────────┐
   │ 仓端 IoT 网关│◄───────►│ 边缘服务器  │         │ LoRa 网关等  │
   └──────┬──────┘         └──────┬──────┘         └──────┬──────┘
          │                       │                       │
          └───────────┬───────────┴───────────┬───────────┘
                      ▼                       ▼
              温湿度/水浸/入侵             摄像头 / 定位终端
```

**灵活部署要点**：同一后台可同时接入多仓、多模式；单仓可「局域网主用 + 4G 备用」双链路。

## 2. 传感器 → 后台 → APP 数据流

```
传感器采样
  → 网关协议转换 / 本地缓存 / 边缘初判
  → MQTT telemetry（或 HTTPS 批量）
  → Broker 鉴权与 Topic 隔离
  → 物联网服务解析写入时序库
  → 规则引擎（阈值、围栏、库容）
  → 告警服务 → 推送网关 → 管控 APP
  → 监测 API / WebSocket → APP 图表与状态灯
```

## 3. APP 与后台通信剖面

| 层级 | 协议 | 端口（示例） | 说明 |
| --- | --- | --- | --- |
| 业务 | HTTPS REST | 443 | 开单、查询、配置 |
| 实时 | WSS | 443 | 告警、监测刷新 |
| 上传 | HTTPS multipart | 443 | 照片、报表 |
| 设备 | MQTTS | 8883 | 遥测、定位、指令 |

鉴权：APP 使用 JWT；设备使用证书或设备密钥。

## 4. 监管对接逻辑位

```
业务事件（入/出库、重大告警、转移打卡）
  → 对接适配器（字段映射 / 签名 / 重试）
  → 省/部生态环境信息系统 OpenAPI 或交换节点
  ← 联单号回写、抽查拉取台账
```

OpenAPI 命名空间：`/api/v1/open/*`（详见主设计文档第 8 章）。
