智能危废管控系统 · 原型总览（V2.1）

网页前台为上下顶栏菜单布局，只做数据展示；网页后台只做人员权限与主数据录入；管控 APP 负责展示 + 运输打卡 / 盘点扫码 / 入出库扫码等现场执行。

网页前台 · 上下布局

数据展示门户

顶部菜单栏 + 全宽内容区。告警、物资、监测、定位、围栏状态只读展示。

  • 顶栏：工作台 / 告警 / 物资 / …
  • 无左侧导航、无扫码执行
 网页后台 · 管理录入

管理与数据录入

人员角色权限、开单发码、物资/阈值/围栏/单元/设备。不做现场打卡扫码。

  • 人员 · 角色权限矩阵
  • 盘点任务创建（扫码在 APP）
  • 打卡记录只读审计
 管控 APP · 展示+执行

移动端现场作业

态势展示与告警推送；运输打卡、盘点扫码、入出库扫码确认。

  • 执行：打卡 / 盘点 / 入出库扫码
  • 展示：物资 / 告警 / 监测 / 定位
