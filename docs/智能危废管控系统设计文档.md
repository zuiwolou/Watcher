## 1. 文档说明

### 1.1 编制目的

本文档定义智能危废管控系统的整体架构、**三端（网页前台 / 网页后台 / 管控 APP）职责分工**、**人员与功能权限体系**、通信组网方案、业务模块设计、接口规范、部署方案及监管对接标准。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 职责任分离 | 展示与管理分离：前台/APP 看数，后台管人、管权、管录入 |
| 权限最小化 | 基于角色的功能权限 + 仓体数据范围，可审计 |
| 合规优先 | 对齐危废贮存、转移联单、台账等监管要求 |
| 一物一码 | 唯一码贯穿全生命周期 |
| 多模组网 | 局域网 / 物联网 / 公网灵活部署 |
| 可追溯 | 人员操作、告警、轨迹全程留痕 |

### 1.3 术语

| 术语 | 含义 |
| --- | --- |
| 网页前台 | PC 端数据展示门户（Dashboard），只读为主 |
| 网页后台 | PC 端管理与数据录入控制台（Admin） |
| 管控 APP | 移动端只读展示与告警接收（本期不做管理录入） |
| RBAC | 基于角色的访问控制 |
| 权限点 | 可授予角色的最小功能能力（如 `material:view`） |

## 3. 人员管理与权限架构（RBAC）

### 3.1 模型

```
人员 User ──N:N── 角色 Role ──N:N── 权限点 Permission
    │                  │
    └── 数据范围 Scope（可访问的仓库/组织）
```

| 实体 | 说明 |
| --- | --- |
| 人员 | 账号、姓名、手机、部门、状态（启用/停用）、所属组织 |
| 角色 | 预置 + 自定义；绑定一组权限点 |
| 权限点 | `资源:动作`，如 `alarm:view`、`geofence:edit` |
| 数据范围 | 全部仓 / 指定仓列表；与功能权限同时生效 |

### 3.2 预置角色（可改）

| 角色 | 典型用途 | 默认能力摘要 |
| --- | --- | --- |
| 系统管理员 | 后台全权 | 人员权限 + 全部业务配置与录入 |
| 业务管理员 | 日常业务录入 | 仓储/物资/盘点/单元/围栏/阈值，无改权限体系 |
| 安全员 | 环境与告警 | 阈值、围栏、告警处置、监测设备；前台/APP 查看 |
| 仓管员 | 库内业务 | 入出库、物资、盘点；前台查看 |
| 只读观察员 | 领导/参观 | 仅网页前台 + APP 只读，无后台 |

### 3.3 权限点清单（与功能模块对齐）

| 模块 | 权限点 | 说明 |
| --- | --- | --- |
| 人员权限 | `user:view/edit` `role:view/edit` | 仅管理员 |
| 仓储 | `warehouse:view` `inbound:edit` `outbound:edit` `code:issue` | 开单与发码在后台 |
| 物资 | `material:view` `material:edit` `material:export` | |
| 盘点 | `inventory:view` `inventory:create` `inventory:scan` | 后台建任务；APP 扫码实盘 |
| 预警 | `threshold:edit` `alarm:view` `alarm:ack` | |
| 运输 | `checkin:exec` `unit:edit` `track:view` | 打卡执行仅 APP |
| 围栏 | `geofence:view` `geofence:edit` | |
| 监测 | `monitor:view` `device:edit` | |
| 门户 | `portal:access` `admin:access` `app:access` | 端访问权 |
| 对接 | `openapi:config` | 监管接口 |

**鉴权规则**：请求携带 JWT → 解析用户角色与权限点 → 校验功能权限 → 再过滤数据范围（仓库 ID）。无 `admin:access` 不可进网页后台；无 `portal:access` 不可进网页前台；无 `app:access` 不可登录 APP。

### 3.4 人员管理流程（网页后台）

1. 管理员创建人员账号 → 分配部门与可访问仓库。
2. 为人员绑定一个或多个角色（或直接勾选权限点，高级模式）。
3. 启用账号；首次登录强制改密（可选）。
4. 变更权限即时生效（刷新 Token 或短 TTL）。
5. 停用账号立即拒绝新会话；操作日志保留。

### 3.5 权限与三端菜单

- 网页前台：**顶部菜单栏**按 `*:view` 显隐，无左侧栏。
- 网页后台：左侧导航按管理/录入权限显隐。
- APP：展示菜单 + 执行菜单（打卡/盘点扫码/入出库扫码）按 `checkin:exec`、`inventory:scan` 等下发。

## 4. 整体技术架构

### 4.1 逻辑架构

```
┌────────────────────────────────────────────────────────────────────┐
│ 展现层                                                              │
│  网页前台(Portal) │ 网页后台(Admin) │ 管控APP(只读)                   │
└────────────────────────────┬───────────────────────────────────────┘
                             │ HTTPS / WSS + JWT
┌────────────────────────────▼───────────────────────────────────────┐
│ 接入层：API Gateway │ 认证中心(RBAC) │ MQTT Broker │ 推送网关         │
└────────┬───────────────────────────────┴───────────┬───────────────┘
         │                                           │
┌────────▼──────────────┐                 ┌──────────▼───────────────┐
│ 业务服务               │                 │ 物联网服务                 │
│ 人员权限│仓储│物资│盘点 │                 │ 采集│规则│告警│定位│视频   │
│ 运输│围栏│台账│对接     │                 │                         │
└────────┬──────────────┘                 └──────────┬───────────────┘
         └──────────────────┬────────────────────────┘
                            ▼
         PostgreSQL │ 时序库 │ Redis │ 对象存储 │ 消息队列
                            ▲
                     边缘传感器 / 网关 / 定位 / 摄像
```

### 4.2 通信与组网（摘要）

支持**局域网 / 物联网 / 公网**多模组网：

- 传感器 → IoT 网关（缓存、断点续传）→ MQTT/HTTPS → **MQTT 适配层（Schema 映射）** → 规则引擎 → 告警推送至前台/APP。
- 三端统一走 API Gateway；设备走 MQTTS。
- 组网示意见 `docs/架构与组网示意图.md`。

### 4.3 客户端与协议

| 通道 | 协议 | 用途 |
| --- | --- | --- |
| 业务 API | HTTPS + JSON | 三端共用，按权限裁剪 |
| 实时 | WSS | 告警、监测、定位刷新 |
| 推送 | APNs/厂商推送 | APP 告警通知 |
| 设备 | MQTTS | 遥测 / 事件 / 定位 / 下行指令 |

### 4.4 MQTT 可自定义数据结构（要点）

不同厂商网关报文结构不一，系统通过后台可配置的 **Schema Profile + 字段映射**，将原始 JSON 归一为 **Canonical 内部模型**，业务与告警只认标准字段。

| 概念 | 作用 |
| --- | --- |
| Schema Profile | 报文模板：JSON Schema 校验 + mapping 规则 + 版本 |
| Topic Template | 可自定义 Topic 模式与变量抽取 |
| Device Binding | 设备绑定所用 Profile |
| Canonical | `hw.canonical.v1` 标准信封（telemetry / event / location / heartbeat / command） |

**标准遥测指标键**：`temperature`、`humidity`、`waterLeak`、`intrusion`；扩展走 `metrics.custom.*`。

**完整字段定义、映射样例、API 与 dry-run**：见专篇  
[`docs/MQTT可自定义数据结构规范.md`](MQTT可自定义数据结构规范.md)  
后台原型：`prototypes/web-admin/mqtt-schema.html`。

## 6. 网页后台详细设计（管理 + 录入）

> 原型：`prototypes/web-admin/`

### 6.1 定位

系统**唯一管理与录入端**（本期）：人员权限、业务单据、主数据、阈值与围栏、设备与对接。

### 6.2 模块设计

#### 6.2.1 人员与权限

- 人员列表：新建/编辑/停用、重置密码、分配仓库范围。
- 角色管理：勾选权限点矩阵；预览「该角色可见菜单」。
- 操作审计：登录、权限变更、开单、阈值/围栏变更。

#### 6.2.2 仓储与唯一码

- 入库申报审核、入库开单、批量生成/打印唯一码、出库开单。
- 状态机：唯一码 `已发放→在库→在途→已签收`；联单号字段预留。

#### 6.2.3 物资与盘点录入

- 物资档案维护、库存调整（需审批流可配）。
- 创建盘点任务、录入/导入实盘、生成报表、差异处理。

#### 6.2.4 预警阈值

- 按仓配置温度/湿度上下限、库容上限、水浸/入侵策略、通知人。

#### 6.2.5 运输单元管理

- 运输车 / 转运仓 CRUD、绑定定位设备。
- **不在后台做运输打卡**；打卡由 APP 现场执行，后台仅可查看打卡记录列表（只读审计）。

#### 6.2.6 电子围栏

- 地图绘制圆形/多边形、滞回、生效时段；保存下发规则引擎。

#### 6.2.7 监测设备与对接

- 网关/传感器/摄像头注册；监管 OpenAPI 开关与映射。

#### 6.2.8 MQTT 数据结构（可自定义）

- 维护 Schema Profile（样例报文、字段映射、发布版本）。
- 维护 Topic 模板；设备绑定 Profile。
- 提供 dry-run：粘贴原始 JSON 预览 Canonical 结果。
- 权限：`mqtt:schema:edit`（建议管理员/运维）。
- 详设见 `docs/MQTT可自定义数据结构规范.md`。

### 6.3 协作示例：开单（后台）→ 扫码确认（APP）

```
后台创建入库单并生成唯一码
  → 仓管员 APP 扫码上架确认 → 库存生效 → 前台/APP 展示刷新
运输任务在后台关联出库单与车辆后
  → 驾驶员 APP 运输打卡（扫码+拍照+定位）→ 前台地图可见轨迹
```

## 7. 管控 APP 详细设计（展示 + 现场执行）

> 原型：`prototypes/app/`

### 7.1 定位

移动端 = **态势展示** + **现场执行**（扫码/打卡）。  
不做：人员权限、阈值/围栏绘制、物资档案录入、开单制单（制单在后台）。

### 7.2 功能列表

| 类型 | 模块 | 能力 |
| --- | --- | --- |
| 展示 | 首页 / 物资 / 告警 / 监测 / 定位 / 围栏状态 | 与前台同类只读数据，移动适配 + 推送 |
| **执行** | **运输打卡** | 扫唯一码、拍照、采集合规位置、提交节点 |
| **执行** | **库存盘点** | 领取后台下发的盘点任务，连续扫码实盘 |
| **执行** | **入/出库扫码** | 对已开单据做扫码上架或扫码出库确认 |
| 账户 | 我的 | 改密、退出；无权限配置入口 |

### 7.3 与后台/前台关系

| 动作 | 发起端 | 执行端 | 展示端 |
| --- | --- | --- | --- |
| 开单/发码 | 后台 | — | 前台/APP |
| 运输打卡 | — | **APP** | 前台地图 |
| 盘点任务 | 后台创建 | **APP 扫码** | 前台报表 |
| 阈值/围栏 | 后台配置 | — | 前台/APP 状态 |

## 8. 接口规范（摘要）

### 8.1 认证与权限

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/auth/login` | 返回 token + 权限点列表 + 可访问端 |
| GET | `/api/v1/me/permissions` | 当前用户权限与数据范围 |
| CRUD | `/api/v1/admin/users` | 人员管理 |
| CRUD | `/api/v1/admin/roles` | 角色与权限点绑定 |

### 8.2 展示类（前台/APP 共用）

`GET /materials` · `GET /alarms` · `GET /warehouses/{id}/monitor` · `GET /transport/units/locations` · `GET /geofences` · `GET /inventories/{id}/report`

### 8.3 管理录入类（仅后台 + 对应权限）

`POST /inbound/orders` · `POST /outbound/orders` · `PUT /thresholds` · `PUT /geofences` · `POST /transport/units/{id}/bind-device` · `POST /transport/checkins` · …

### 8.4 监管 OpenAPI

`/api/v1/open/*`（台账、库存快照、告警、联单绑定），见部署与对接专章。

## 9. 部署与组网

- 服务器：LB + API 集群 + MQTT + 业务库/时序库/对象存储。
- 仓体：IoT 网关 + 传感器 + 摄像 + 可选 4G 备份；支持局域网/物联网/公网组合。
- 网页前台/后台可同域不同路径（`/portal`、`/admin`）或子域名，统一 SSO。
- APP 企业分发；开放展示与现场执行（打卡/扫码）及推送证书配置。

---

## 10. 监管合规与对接

保持：转移联单字段、电子台账、库龄/库容预警、轨迹证据链、环境告警、省平台 OpenAPI/SFTP 交换。人员操作与权限变更纳入审计，满足内部合规与外部抽查。
