# 架构与组网示意图（V2.1）

## 1. 三端分工

```
┌──────────────────────────────────────┐
│ 网页前台 Portal（上下布局）            │
│ 顶栏菜单 → 全宽展示区                  │
│ 告警 / 物资 / 报表 / 监测 / 地图 / 围栏 │
└──────────────────┬───────────────────┘
                   │ 只读 API / WSS
┌──────────────────┼───────────────────┐
│                  ▼                   │
│         API + RBAC 鉴权中心           │
│                  ▲                   │
└──────────────────┼───────────────────┘
         ┌─────────┴─────────┐
         ▼                   ▼
┌─────────────────┐  ┌─────────────────┐
│ 网页后台 Admin   │  │ 管控 APP         │
│ 人员权限         │  │ 【展示】态势告警  │
│ 开单发码         │  │ 【执行】         │
│ 物资/阈值/围栏   │  │  运输打卡扫码    │
│ 盘点任务创建     │  │  盘点扫码        │
│ 单元/设备        │  │  入出库扫码确认  │
│ （无现场打卡）   │  │                 │
└─────────────────┘  └─────────────────┘
```

## 2. 前台信息架构（上下）

```
┌ brand · 用户 · 链到后台 ─────────────┐
├ 工作台 | 告警 | 物资 | 盘点 | 监测 | … ┤  ← 菜单在上
├──────────────────────────────────────┤
│            内容区（全宽）              │
└──────────────────────────────────────┘
```

## 3. 执行数据流

```
后台：创建入库单 / 盘点任务 / 运输任务
  → APP：扫码执行（打卡 · 实盘 · 上架/出库确认）
  → 业务库更新
  → 前台顶栏模块与 APP 展示页刷新
```

## 4. 组网与 MQTT 自定义报文

```
传感器/网关
  → MQTT Publish（厂商自定义 JSON + 可配 Topic）
  → Topic 匹配 + Schema Profile 校验/字段映射
  → Canonical（hw.canonical.v1）
  → 时序库 / 规则引擎 / 定位
  → 前台与 APP
```

详规：`docs/MQTT可自定义数据结构规范.md`
