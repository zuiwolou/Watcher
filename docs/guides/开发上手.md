# 开发上手

当前进度：**全栈 MVP v0.2** — 详见 [`MVP说明.md`](MVP说明.md)。目录边界见 [`目录说明.md`](目录说明.md)。

## 目录

```
backend/cmd/*          # 进程入口：webhttp / history / push / mqtt
backend/internal/biz   # 业务逻辑库（与 webhttp 同进程）
backend/internal/*     # 各服务私有包
backend/pkg/           # 公共库
backend/configs/       # 本地配置
frontend/admin         # Vue3 管理端 :5173
frontend/portal        # Vue3 门户 :5174
mobile/                # Flutter APP
contracts/             # OpenAPI / Proto / gen
deploy/compose/        # MySQL / Redis / NSQ / etcd / MinIO / EMQX
tools/scripts/smoke.ps1
sql/schema/watcher_schema.sql · sql/data/watcher_data.sql
```

空库可先执行 SQL（见 [`sql/README.md`](../../sql/README.md)），再启动服务。

## 依赖

1. Go 1.22+
2. Node 20+（前端）
3. Flutter 3.16+（可选，APP）
4. MySQL 8（Compose 或本机）

无 Docker 时自行建库：

```sql
CREATE DATABASE watcher DEFAULT CHARACTER SET utf8mb4;
CREATE USER 'watcher'@'%' IDENTIFIED BY 'watcher';
GRANT ALL ON watcher.* TO 'watcher'@'%';
```

## 启动中间件

```bash
docker compose -f deploy/compose/docker-compose.yml up -d
```

## 启动后端（多终端）

```bash
go mod tidy
go run ./backend/cmd/webhttp    # :8080
go run ./backend/cmd/history    # :8082
go run ./backend/cmd/push       # :8083
go run ./backend/cmd/mqtt       # 订 EMQX
```

健康检查：`GET http://127.0.0.1:8080/healthz`  
默认账号：`admin` / `Admin@123`

## 启动前端

```bash
cd frontend/admin && npm i && npm run dev     # :5173
cd frontend/portal && npm i && npm run dev    # :5174
```

Vite 已代理 `/api` → `http://127.0.0.1:8080`。

## 启动 APP

```bash
cd mobile
flutter pub get
flutter run --dart-define=API_BASE=http://10.0.2.2:8080/api/v1
```

## 联调示例（PowerShell）

```powershell
$login = Invoke-RestMethod -Method POST http://127.0.0.1:8080/api/v1/auth/login -ContentType 'application/json' -Body '{"username":"admin","password":"Admin@123"}'
$token = $login.data.accessToken
$h = @{ Authorization = "Bearer $token" }

$mat = Invoke-RestMethod -Method POST http://127.0.0.1:8080/api/v1/materials -Headers $h -ContentType 'application/json' -Body '{"code":"M001","name":"废铅蓄电池","unit":"只"}'
$in = Invoke-RestMethod -Method POST http://127.0.0.1:8080/api/v1/inbound/orders -Headers $h -ContentType 'application/json' -Body (@{warehouseId='WH01';materialId=$mat.data.ID;qty=2} | ConvertTo-Json)
$codes = Invoke-RestMethod -Method POST "http://127.0.0.1:8080/api/v1/inbound/orders/$($in.data.ID)/issue-codes" -Headers $h -ContentType 'application/json' -Body '{"count":2}'
$code = $codes.data[0].Code
Invoke-RestMethod -Method POST "http://127.0.0.1:8080/api/v1/inbound/orders/$($in.data.ID)/confirm" -Headers $h -ContentType 'application/json' -Body (@{uniqueCode=$code;clientRequestId=[guid]::NewGuid().Guid} | ConvertTo-Json)
```

## 接口速览

| 能力 | 路径 |
| --- | --- |
| 鉴权 | `/api/v1/auth/login` · `change-password` · `refresh` |
| 用户/角色 | `/api/v1/admin/users` · `/admin/roles` |
| 仓储主链路 | `/materials` · `/inbound/*` · `/outbound/*` |
| 运输/盘点/审批/巡检 | `/transport/*` · `/inventory/*` · `/approvals/*` · `/inspection/*` |
| 告警/围栏 | `/alarms` · `/thresholds` · `/geofences` · `/monitor/evaluate` |
| 实时流 | `/api/v1/stream`（反代 push） |
| 上传 | `POST /api/v1/media/upload-url` |

OpenAPI：`contracts/opencontracts/openapi.yaml`
