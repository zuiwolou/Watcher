# 架构与组网示意图（V5.1）

> 配套 [`智能危废管控系统设计文档.md`](智能危废管控系统设计文档.md)（选型已全部定稿）

## 1. 五微服务

```
 Portal / Admin (Vue3+Element Plus) / Flutter APP
        │ HTTPS+JSON                 │ WSS：Nginx → WebHTTP 鉴权 → 反代 Push
        ▼                            ▼
 ┌──────────────┐              ┌──────────────┐
 │ svc-webhttp  │─────────────►│  svc-push    │
 │ Gin·Casbin   │              │ Protobuf     │
 │ LDAP         │              └──────▲───────┘
 └──────┬───────┘                     │ NSQ
        │ gRPC mTLS                   │
        ▼                             │
 ┌──────────────┐              ┌──────┴───────┐
 │   svc-biz    │──── NSQ ────►│ svc-history  │
 │ 业务·告警·围栏│              │ MySQL 分区   │
 │ 多级审批·巡检 │              └──────────────┘
 └──────▲───────┘
        │ NSQ
 ┌──────┴───────┐
 │  svc-mqtt    │◄══ MQTTS ══ EMQX ◄══ 设备
 └──────────────┘
```

## 2. 部署

| 平台 | 形态 |
| --- | --- |
| Linux | Docker Compose + systemd |
| Windows | 应用服务 + 中间件均可部署 |
| 存储 | MinIO · MySQL · Redis · etcd · NSQ · EMQX |
| CI/CD | GitHub Actions |

## 3. 数据路径

```
设备 → EMQX → mqtt → NSQ → history / biz / push
人机 → Nginx → webhttp → gRPC → biz | history
实时 → Nginx → webhttp 鉴权 → 反代 push
```
