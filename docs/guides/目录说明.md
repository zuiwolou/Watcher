# 仓库目录说明

按职责划分顶层，一眼区分后端、前端、契约与运维。

```text
/
  backend/       Go 服务进程入口、领域库、共享 pkg、运行配置
  frontend/      Vue3 Admin / Portal
  mobile/        Flutter APP
  contracts/     OpenAPI、Protobuf 与生成代码
  deploy/        Compose / systemd / nginx / windows
  docs/          design · requirements · guides · plan
  sql/           默认 SQL：schema（表结构）+ data（表数据）
  tools/         脚本与辅助工具（如冒烟）
  archive/       历史原型（仅交互参考，非实现）
  bin/           本地构建产物（gitignore）
```

## sql

| 路径 | 职责 |
| --- | --- |
| `sql/schema/watcher_schema.sql` | 全量表结构 |
| `sql/data/watcher_data.sql` | 默认角色、权限、管理员、默认仓 |

详见 [`sql/README.md`](../../sql/README.md)。

## backend

| 路径 | 职责 |
| --- | --- |
| `cmd/webhttp` · `cmd/history` · `cmd/push` · `cmd/mqtt` | **唯一**进程入口 |
| `internal/biz` | 领域逻辑库（暂与 webhttp 同进程，无独立 cmd） |
| `internal/webhttp` · `internal/history` | 各服务私有实现 |
| `pkg/` | 跨服务公共库（auth、config、bus…） |
| `configs/` | `config.yaml` 等 |

启动：`go run ./backend/cmd/webhttp`

## frontend / mobile

| 路径 | 说明 |
| --- | --- |
| `frontend/admin` | 管理端 :5173 |
| `frontend/portal` | 门户 :5174 |
| `mobile/` | Flutter |

## contracts

人机与服务契约唯一来源：`openapi/`、`proto/`、`gen/`。

## archive

原 `archive/prototypes/` 已迁入；实现以 `frontend/`、`mobile/` 为准。
