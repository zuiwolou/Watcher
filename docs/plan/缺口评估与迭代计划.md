## 1. 总体结论

| 维度 | 判定 |
| --- | --- |
| MVP 0.3 | **已交付**：主链路入库→锁定→签收、审批、巡检、阈值告警、WSS Protobuf、Admin/Portal 核心页、APP 执行骨架可跑 |

## 4. 迭代计划

原则：**先堵验收漏洞（P0）→ 再加深体验与监管真联调（P1）→ 最后非功能与微服务拆分（P2/架构）**。每阶段出口可演示、可勾验收要点。

### 阶段 E0 — 契约与基线冻结 ✅（2026-11-09）

| 任务 | 交付 | 关联 | 状态 |
| --- | --- | --- | --- |
| 同步 OpenAPI 至代码真实路由 | `contracts/openapi/openapi.yaml` → **0.3.0**（含盘点 submit/post/lines、巡检、审批 act、告警 ack/close、stream 等） | CONTRACT-01 | ✅ |
| 冻结 MVP tag | `v0.3.0-mvp` | QA-03 | ✅ |
| 文档口径统一 | README / MVP说明 / 实施计划交叉引用本文 | — | ✅ |

**出口**：契约可被前端/APP 对照；基线可回滚。  
**CONTRACT-01 余量**：请求/响应字段级 schema 仍可继续加厚（当前以路径+方法+关键 body 对齐为准）。

## 6. 每阶段验收清单（摘要）

### E1

- [ ] 盘点过账改变库存且可追溯
- [ ] 模拟越界产生告警并可在 Portal/Admin/APP 看到
- [ ] 告警历史查询有数据
- [ ] 唯一码作废成功/已签收拒绝
- [ ] 监管独立凭证只读查询成功

### E2

- [ ] Admin 可管设备与编辑用户；LDAP 可登录
- [ ] Portal 有盘点/巡检报表与唯一码台账
- [ ] 无权限菜单隐藏；直链有 403 或等价空态
- [ ] WSS 重连后快照纠偏

### E3

- [ ] 执行主路径为「选任务 → 连扫 → 进度」
- [ ] 照片对象在 MinIO 可访问
- [ ] APP 收 WSS 或等价实时；角标正确
- [ ] iOS 工程可构建；Token 非明文 SharedPreferences 裸存
- [ ] 断网 Outbox 恢复后无重复账

### E4～E5

- [ ] 监管出站对真实通道成功/可重试
- [ ] TLS 与 Origin 收紧
- [ ] CI 全绿（含 Flutter）；验收记录归档

## 7. 风险与决策点

| 风险 | 影响 | 建议决策 |
| --- | --- | --- |
| 百度 AK / 推送证书延期 | E4、APP 地图与推送 | 继续 Leaflet + 本地通知保底；验收单单独标注依赖 |
