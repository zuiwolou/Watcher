## 1. 文档说明

### 1.1 目的

定义移动端的**导航结构、页面布局、手势与现场作业交互、权限裁剪、离线与推送体验**，供 UI/Flutter 开发与验收。接口与数据格式见 [`需求-后端.md`](需求-后端.md)。

### 1.2 产品原则

| 原则 | 说明 |
| --- | --- |
| 单手优先 | 主操作在拇指区；扫码全屏沉浸 |
| 执行可追溯 | 打卡/确认必须可附带拍照、定位（按业务配置） |
| 权限裁剪 | 无对应权限不出现 Tab/入口 |
| 弱网可用 | 执行类支持 Outbox 队列，恢复后幂等上送 |
| 与 Web 一致 | 同一权限点、同一状态机语义；不在本地放宽状态 |

### 1.3 角色典型路径

| 角色 | 主要使用 |
| --- | --- |
| 仓管员 | 入出库扫码、盘点、告警查看 |
| 驾驶员 | 运输打卡、地图；签收需另授 `outbound:confirm` |
| 巡检员 | 巡检执行 |
| 安全员/领导 | 告警、监测、围栏只读 |

## 2. 全局框架与视觉

### 2.1 导航结构

```
底部 Tab（按权限动态）
├ 首页          ← app:access
├ 告警          ← alarm:view
├ 监测          ← monitor:view（可与首页合并，按信息架构二选一）
├ 执行          ← 任一 confirm/scan/checkin/inspection:exec 时出现
└ 我的
```

**执行**为聚合页，内含入口卡片：

| 入口卡片 | 权限 |
| --- | --- |
| 入库确认 | `inbound:confirm` |
| 出库确认 / 签收 | `outbound:confirm` |
| 运输打卡 | `checkin:exec` |
| 盘点扫码 | `inventory:scan` |
| 巡检打卡 | `inspection:exec` |

物资、地图、围栏可作为首页宫格或二级页（需对应 `*:view`）。

### 2.2 视觉与动效

| 项 | 要求 |
| --- | --- |
| 风格 | 与 Portal 主色体系统一的工业安全风；大触摸热区 ≥ 44pt |
| 扫码框 | 深色蒙版 + 亮色取景框；扫中震动/短音反馈 |
| 成功态 | 全屏或底部 Sheet 绿勾 + 唯一码摘要；1.5s 后可自动回扫下一码 |
| 失败态 | 红提示 + 原因（状态不允许、无权限、网络） |
| 动效 | 页转场、扫码成功、告警角标；避免过度装饰 |

### 2.3 登录与账户

| 画面 | 交互 |
| --- | --- |
| 登录 | 账号密码 / LDAP；错误提示明确 |
| 强制改密 | `mustChangePassword` 时阻塞主界面 |
| Token | Access 30min；后台 Refresh；失败退登录 |
| 我的 | 头像/姓名、权限摘要、改密、缓存清理、关于、退出 |
| 禁止 | 无角色配置、无用户管理 |

### 2.4 推送与实时

| 通道 | 行为 |
| --- | --- |
| 系统通知 | APNs / 厂商；**仅摘要**（级别、标题、时间）；点击进告警详情 REST |
| WSS | 登录后连接；收 Protobuf；更新首页卡片与告警列表 |
| 角标 | 未确认告警数 |

### 2.5 系统权限

首次进入相关功能时申请：相机、定位、通知、（可选）相册。拒绝定位时：**禁止提交**要求定位的打卡，并引导去设置。

## 3. 展示类页面

### 3.1 首页（工作台）

```
┌ 仓名 / 连接状态 ──────────┐
├ 未确认告警 | 在途 | 环境摘要 ┤
├ 快捷入口（有权执行卡片）───┤
└ 最新告警 3 条 ─────────────┘
```

下拉刷新；卡片点击进入列表或执行页。

### 3.2 告警

| 元素 | 列表（状态色条）+ 筛选（状态/级别）+ 详情页 |
| --- | --- |
| 详情 | 规则、测点、时间、关联设备；确认按钮需 `alarm:ack` |
| 确认 | 可填备注；成功后列表更新 |

### 3.3 物资

- 搜索唯一码/名称；列表只读；详情含状态与简单时间线。
- 支持扫码查询（打开扫码 → 跳详情）。

### 3.4 监测

- 测点卡片实时值；点进曲线页（选时间范围，REST 历史）。
- 异常变色并跳转告警。

### 3.5 地图 / 定位

- 百度地图：运输单元实时点；选任务看轨迹。
- 只读；无编任务。

### 3.6 围栏

- 地图展示围栏与自身/单元位置；越界事件列表。
- 只读。

### 3.7 盘点报表 / 巡检记录（只读入口）

- 可在「我的」或首页进入已完成任务摘要；执行仍走「执行」Tab。

## 4. 执行类页面（核心）

### 4.1 通用扫码交互

```
进入执行页 → 选择单据/任务（若需要）→ 进入扫码全屏
  → 识别唯一码 → 本地初验格式
  → 调用 API（带定位/照片若需要）
  → 成功：反馈 + 继续扫 / 完成
  → 失败：展示 STATE_INVALID 等原因，不关闭扫码页（可配置）
```

| 能力 | 说明 |
| --- | --- |
| 手输 | 扫码失败可手动输入唯一码（仍走服务端校验） |
| 手电筒 | 扫码页开关 |
| 连扫 | 入库/盘点支持连续模式 |

### 4.2 入库确认（`inbound:confirm`）

| 步骤 | 画面 |
| --- | --- |
| 1 | 待确认入库单列表（单号、物资摘要、待扫数量） |
| 2 | 选单后扫码上架；进度「已扫/应扫」 |
| 3 | 可选拍照；提交单码或批量提交策略以后端为准 |
| 完成 | 单据完成后列表移除或标绿 |

### 4.3 出库确认 / 签收（`outbound:confirm`）

| 场景 | 交互 |
| --- | --- |
| 出库扫码确认 | 待出库单列表 → 扫码 → 状态更新 |
| **签收** | 在途任务/出库单 → 确认签收（扫码或单据确认）→ 唯一码已签收 |

与运输打卡分工清晰：打卡记节点轨迹；**签收改业务状态**用本权限。

### 4.4 运输打卡（`checkin:exec`）

```
┌ 我的运输任务列表 ─────────────┐
├ 任务详情：节点（发车/途经/到达）┤
├ 打卡页：扫码 + 拍照 + 定位状态 ┤
└ 提交成功 → 时间线增加一条 ────┘
```

| 规则 | 定位精度不足时警告或禁止（可配）；必拍节点未拍照不可提交 |
| --- | --- |
| 地图 | 可查看本任务计划路线与已打点 |

### 4.5 盘点扫码（`inventory:scan`）

| 步骤 | 领取/选择进行中任务 → 连续扫码计入实盘 → 可查看已扫清单 → 提交任务 |
| --- | --- |
| 异常 | 不在任务范围的码：提示并记录或忽略（按产品规则，需与后端一致） |
| 完成后 | 等待 Admin 差异处理；APP 显示「已提交」 |

### 4.6 巡检打卡（`inspection:exec`）本期

```
任务列表 → 路线点列表（序）→ 到点：
  定位校验（可选电子围栏半径）
  必拍则拍照
  正常 / 异常（异常填说明，可触发转告警）
  → 下一点 → 全部完成提交
```

| 画面要点 | 点状态：未到/已打卡/异常；照片缩略图可回看 |
| --- | --- |

## 5. 离线与弱网

| 场景 | 行为 |
| --- | --- |
| 执行提交失败 | 入 Outbox，状态「待同步」；有网后自动重试 |
| 幂等 | 客户端生成 `clientRequestId`；服务端去重 |
| 冲突 | 服务端 `STATE_INVALID` → 标失败，需人工处理，不盲重放 |
| 展示类 | 弱网可读缓存；标明「缓存时间」 |

## 8. 验收要点

1. 无权限不出现执行入口；驾驶员无签权不能签收。
2. 扫码成功/失败反馈明确；非法状态码不可变成功。
3. 打卡含定位与照片策略按配置强制。
4. 通知只有摘要，点进详情为网络拉取。
5. 断网扫码入队，恢复后数据与 Admin/Portal 一致且无重复账。
6. 巡检顺序点可完成；异常能看到记录。
7. 强制改密不可跳过。
